# Personal GitHub Copilot Defaults

Follow repository custom instructions and the closest `AGENTS.md`. Match
adjacent code patterns, preserve privacy and security boundaries, avoid
unrelated rewrites, and run only the repository-designated linter/analyzer by
default plus its context validator when context changes. Standalone
typechecking, tests, builds, packaging, coverage, and E2E require an explicit
user request. Do not suggest destructive operations, deployments, pushes, or
secret changes without explicit confirmation.
