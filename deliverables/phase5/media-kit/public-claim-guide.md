# Panduan Klaim Publik Gamblock-AI

Panduan ini berlaku untuk laporan, presentasi, poster, video, artikel, website,
media sosial, demo, wawancara, dan materi sponsor/mitra.

## Boleh digunakan sekarang

- “Gamblock-AI adalah prototipe PKM-KC 2026 untuk mahasiswa.”
- “Jalur utama telah terhubung sebagai code-complete prototype.”
- “Klasifikasi dan keputusan deteksi dirancang serta diimplementasikan untuk
  berjalan pada perangkat.”
- “Ekstensi browser adalah sensor pasif; blocking authority berada pada
  aplikasi Android/Windows.”
- “Backend tidak menerima URL, domain, DOM, riwayat, screenshot, atau skor per
  halaman.”
- “Pattern Interrupt prototipe berlangsung tujuh detik dan memiliki
  reduced-motion serta grounding/help.”
- “Alat evaluasi Phase 4 telah terinstrumentasi; pengujian eksternal menunggu.”
- “Gamifikasi difokuskan pada tindakan belajar/pemulihan yang bermakna dan tidak
  menggunakan loot box atau variable reward.”

## Hanya boleh setelah evidence gate terkait lolos

| Klaim                                           | Bukti minimum                                                        |
| ----------------------------------------------- | -------------------------------------------------------------------- |
| Nilai Precision/Recall/F1/FPR                   | Dataset card, frozen split, final evaluator report, reviewer, hash   |
| “meminimalkan false positive kampus/pemerintah” | Slice government/education, target decision, error analysis          |
| “latensi di bawah 200 ms”                       | Full input-to-visible device matrix dan approved percentile gate     |
| “tahan kill/uninstall”                          | Safe Android/Windows resilience matrix tanpa unsafe mechanism        |
| “meningkatkan retensi”                          | Approved definition/cohort/consent/suppressed result                 |
| “membantu outcome psikologis”                   | Ethics-approved study dan wording sesuai desain/hasil                |
| “production-ready”                              | Signed release, delivery, device/security/accessibility/ops evidence |
| “telah disubmit/dipublikasikan”                 | Receipt/URL, owner, date, artifact hash                              |

## Jangan digunakan

- “100% akurat”, “tanpa false positive”, “memblokir semua judi”, atau “anti
  bypass”.
- “100% aman/privat” atau “semua data tetap lokal”.
- “tidak bisa dihapus”, “mustahil dimatikan”, atau klaim device-owner tersembunyi.
- “menyembuhkan kecanduan”, “terapi”, “diagnosis”, “terbukti mengubah
  perilaku”, atau “mencegah bunuh diri”.
- “pendamping dapat memantau aktivitas pengguna”.
- Angka dari `reported_metrics_unverified` sebagai hasil penelitian.
- Testimoni, foto, suara, atau identitas mahasiswa tanpa publication consent.

## Koreksi klaim

Jika klaim publik keliru, hentikan reuse, catat kanal/URL/tanggal, publikasikan
koreksi dengan bahasa jelas, tautkan versi bukti yang benar, dan tambahkan
revision record pada social/publication archive. Jangan menghapus bukti koreksi
kecuali publikasinya sendiri menimbulkan risiko privasi atau keselamatan.
