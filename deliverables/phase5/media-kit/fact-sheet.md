# Gamblock-AI — Fact Sheet

## Ringkas

Gamblock-AI adalah prototipe PKM-KC 2026 dari Universitas Teknologi Yogyakarta
untuk membantu mahasiswa menghadapi akses judi online melalui deteksi lokal,
Pattern Interrupt, Social Accountability Protocol, dan web regulasi diri.

## Empat pilar

1. **Hybrid Analysis pada perangkat** — aturan URL, DOM terbatas,
   Bag-of-Words, dan Logistic Regression.
2. **Pattern Interrupt** — jeda visual tujuh detik dengan reduced-motion dan
   grounding/help.
3. **Social Accountability Protocol** — pendamping berbasis consent dan
   persetujuan eksplisit untuk pelepasan perlindungan.
4. **Web regulasi diri** — intention, check-in, education, mission, skill, dan
   weekly review sebagai loop yang koheren.

## Batas data

Tetap pada perangkat: URL, domain, DOM, title/headings/anchor, history,
screenshot, feature vector, rule hits, dan per-page score.

Dapat diproses server sesuai tujuan/consent: akun, relationship, approval,
recovery sukarela, agregat non-rekonstruktif, konten publik, dan metadata rilis.

## Platform

- Android: Chrome dan Microsoft Edge yang didukung Accessibility Service.
- Windows: Chrome/Edge extension pasif + LocalSystem service + user-session
  Flutter agent.
- Website: recovery, accountability, education, Learning Hub, dan transparansi.

## Status bukti

- Prototipe utama: code-complete.
- Model: trained artifact integrated; project evaluation belum selesai.
- Phase 4: instrumented; dataset/device/cohort/ethics/reviewer evidence menunggu.
- Phase 5: repository preparation implemented; external approval, submission,
  release, ownership, rendering, dan publication records menunggu.

## Pesan keselamatan

Gamblock-AI adalah alat bantu kontrol diri dan pencegahan, bukan terapi,
diagnosis, cure, atau jaminan. Pendamping mendukung tanpa melihat browsing atau
detail pemulihan pribadi. Pengguna tetap memiliki jalur unsafe exit, emergency
recovery, bantuan, export/delete, dan research withdrawal yang terpisah.
